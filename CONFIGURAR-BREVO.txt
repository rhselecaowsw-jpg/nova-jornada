O QUE AINDA DEPENDE DA CONTA BREVO

1. Criar no Brevo a lista: Diagnóstico Nova Jornada.
2. Criar os atributos de contato personalizados:
   PERFIL
   DIFICULDADE
   ORIGEM
3. Criar um formulário de inscrição com os campos:
   FIRSTNAME
   EMAIL
   PERFIL
   DIFICULDADE
   ORIGEM
4. Copiar a URL de processamento/action fornecida pelo Brevo.
5. Abrir script.js e localizar:

   brevoFormEndpoint: ""

6. Colar a URL entre as aspas, por exemplo:

   brevoFormEndpoint: "URL_FORNECIDA_PELO_BREVO"

IMPORTANTE
- Não cole chave de API no JavaScript do site.
- O envio real e a sequência automática só começam depois que a URL do formulário Brevo for inserida.
- Faça um cadastro de teste antes de publicar.
